Compiler Contract
  • AI explains the repository; static analysis establishes what actually exists: LLMs are strictly bounded by deterministic graph nodes.
  • Strict read-only analysis: Zero arbitrary code execution, zero modifications outside ephemeral storage.
  • Analysis isolation boundary enforced by AnalysisId: Hard separation ensuring zero cross-tenant contamination.
Runtime Semantics
  • Pipeline lifecycle strictly progresses from Created through Indexing or halts at Failed. State machine guarantees valid states.
  • Every architectural claim requires verified source location evidence. Claims without file paths and line ranges are discarded.
  • Multi-path execution decouples relational indexing from vector indexing. Graph models and pgvector stores update asynchronously.
