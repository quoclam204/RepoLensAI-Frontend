Compiler Contract & Architecture Principles
  • AI explains the repository; static analysis establishes what actually exists: LLMs are strictly bounded by deterministic graph nodes.
  • Strict read-only analysis: Zero arbitrary code execution, zero disk mutations outside ephemeral scratch storage.
  • Isolation boundary: Hard isolation enforced per AnalysisId preventing cross-tenant code leakage.
Runtime Semantics & Execution Rules
  • State-machine progression: Pipeline lifecycle strictly progresses from Created through Indexing or terminates at Failed.
  • Grounded citation invariant: Every architectural claim requires verified source location evidence (file path + line span).
  • Decoupled multi-path execution: Relational graph persistence is decoupled from vector embeddings and RAG indexing.
